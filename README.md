# Personal Journal Manager

## 1. Project Description
Personal Journal Manager is a Python-based application that allows users to manage their personal journal entries easily.

Users can add new journal entries, view all saved entries, search for specific entries using keywords or dates, and delete all journal entries.

Each journal entry is automatically saved with the current date and time.

## 2. Objectives
- To create a simple personal journal management system.
- To store journal entries in a text file.
- To search entries using keywords or dates.
- To manage journal entries using Python programming concepts.
- To understand file handling and exception handling in Python.

## 3. Technologies Used
- Programming Language: Python
- Modules: datetime, os
- File Handling: Text File (.txt)
- IDE: Visual Studio Code / Python IDLE

## 4. Features

1. **Add a New Entry:** Users can write and save a new journal entry.
2. **View All Entries:** Displays all previously saved journal entries.
3. **Search for an Entry:** Searches journal entries using keywords or dates.
4. **Delete All Entries:** Deletes all saved journal entries after confirmation.
5. **Exit:** Closes the application.

## 5. Python Concepts Used
- Classes and Objects
- Constructors (`__init__`)
- Methods
- File Handling (`open`, `read`, `write`)
- Exception Handling (`try`, `except`)
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`while`, `for`)
- User Input (`input`)
- Date and Time Handling (`datetime`)
- OS Module (`os.remove`)

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the Python file.
4. Run the program.
5. Select an option from the menu.
6. Enter your journal entry or select another operation.
